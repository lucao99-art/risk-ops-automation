# 🚀 Risk Operations Productivity Tracker

Este projeto foi desenvolvido para automatizar a recolha e análise de métricas de produtividade numa equipa de **Risk Operations (N1)**. A solução substitui o registo manual por um sistema persistente em **SQLite**, gerando relatórios de performance automáticos com **Pandas**.

## 📋 Contexto do Projeto
Durante a minha atuação como Analista de Risco N2, identifiquei um gargalo no acompanhamento da produtividade da equipa. Este script foi criado para:
* **Centralizar os dados** de atendimentos de forma segura.
* **Automatizar o cálculo de KPI** (Chats por hora) baseado numa escala 12x36.
* **Gerar relatórios (CSV)** prontos para serem integrados em ferramentas de BI ou enviados para a gestão.

## 🛠️ Tecnologias Utilizadas
* **Python 3.14**: Linguagem principal para a lógica de automação.
* **Pandas**: Biblioteca utilizada para manipulação de dados e geração de relatórios.
* **SQLite**: Banco de dados relacional para persistência de informações.
* **Programação Orientada a Objetos (POO)**: Estrutura utilizada para garantir a escalabilidade do código.
